# Calorithm

Умный счётчик калорий в Telegram: пользователь пишет в свободной форме о съеденном
("грамм 200 жареной курицы с гречкой", "тарелка куриного супа"); система парсит текст
в структурированный вид, получает КБЖУ, сохраняет и даёт отслеживать потребление.

**Стек:** Python · FastAPI · PostgreSQL · Telegram (aiogram) · LiteLLM · Docker.

## Процесс разработки

Работа ведётся строго по согласованному плану — см. **[docs/development-workflow.md](docs/development-workflow.md)**.
Придерживайся его этапов, порядка и точек ручной валидации (шаги 1–5 и закрытие стадии перед пушем
валидирует автор проекта).
